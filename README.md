# 湖畔慢时光 · V0.3

第一人称 3D 钓鱼游戏，现已加入罗非鱼基础钓鱼流程。自然泥土与碎石岸边、阔叶树林、蓝天白云、花草、浮叶及动态池塘倒影。玩家坐在中间棕橙色椅子的钓位，左侧黑灰椅与右侧米白椅各距玩家约 10 米，右键转头可查看。

[外网试玩](https://tomlose549-droid.github.io/fisher-realm/) · GitHub Pages，无需登录。

## Windows 一键试玩

1. 如收到 ZIP，请先完整解压到普通文件夹。
2. 双击 **启动游戏.cmd**，浏览器会自动打开游戏。
3. 游玩期间保留启动窗口，关闭窗口即停止服务器。

无需安装 Node.js、Python 或任何开发工具；启动器使用 Windows 自带的 PowerShell。全部 3D 依赖已保存在 vendor，运行时不需要联网。请使用支持 WebGL 2 的 Chrome 或 Edge，保持浏览器图形加速开启。不要直接双击 index.html。

启动器默认使用 http://127.0.0.1:5173/，端口被占用时自动尝试 5174–5183，实际地址见启动窗口。服务只监听本机。

## 操作

右上角齿轮为设置入口，点击展开操作提示、回到钓位、画质和全屏。点击面板外、再次点击齿轮或按 Esc 收起；快捷键随时可用。

| 操作 | 功能 |
| --- | --- |
| 空格 | 面向水面抛竿 23 米；本轮未结束时不能重复抛竿 |
| 任意键 | 咬钩后在 1.45 秒内提竿 |
| 拉鱼时左右移动鼠标 | 手动改变鱼竿朝向，镜头自动跟随鱼 |
| 按住 / 松开鼠标左键 | 开始 / 停止收线 |
| 非拉鱼时右键拖动 | 左右上下环顾，可转身看岸边 |
| 方向键 | 转动视角 |
| R / 回到钓位 | 恢复初始视角 |
| F / 全屏按钮 | 切换全屏，Esc 退出 |
| 画质按钮 | 精细 / 流畅切换 |
| 右上角 ? | 查看说明 |
| 触屏单指拖动 | 环顾 |

玩家位置固定，不支持走动。钓鱼需要键盘与鼠标，触屏暂可浏览场景。本版只有罗非鱼，无主动挣扎、商店和背包。

## 已确认的钓鱼规则

- 空格抛出后 6–13 秒随机咬钩，鱼线上下浮动；从咬钩开始算，1.45 秒内按任意键可提竿。超时则鱼脱钩，恢复初始状态。
- 拉鱼时镜头自动跟随鱼的位置；鱼竿保持独立的世界朝向，必须由玩家移动鼠标左右转动。鱼不主动游动，只随收线靠近钓位。
- 收线基准为 3.75 米/秒。鱼竿与鱼的水平夹角 ≤3° 为 120%（4.5 米/秒），>3° 至 30° 为 100%（3.75 米/秒），>30° 至 90° 为 75%（2.8125 米/秒），>90° 为 20%（0.75 米/秒）。松开左键立即停止收线。
- 鱼距钓位 1.25 米时判定钓获。以此刻为 0 秒：0.3 秒后左下角显示浅灰色“罗非鱼已被钓”，0.8 秒后可再次抛竿，4.5 秒开始淡出，淡出动画 0.6 秒。
- 快捷键在咬钩窗口内优先作为提竿键，避免按 F 或 R 提竿时同时触发其他操作。设置面板与说明弹窗内仍以界面操作为准；切走窗口或打开面板会松开收线，避免卡住左键。
- 本版距离按鱼到固定钓位的水平距离计算。

渲染以约 25 FPS 为目标并限帧；植被使用实例化批量绘制，静态树荫预先生成。精细模式保留更清晰的倒影，流畅模式降低分辨率和倒影更新频率，持续低帧率时自动下调渲染分辨率。实际表现取决于设备、浏览器和窗口分辨率。

## 继续开发

- index.html：游戏入口与中文界面。
- main.js：渲染循环、25 FPS 目标、镜头与交互。
- fishing.js：鱼竿、鱼线、抛竿动画、罗非鱼模型及钓鱼界面。
- fishing-rules.js：精确计时、角度效率、收线距离与成功提示时序。
- tests/fishing-rules.test.js：规则边界与计时回归检查；开发环境可运行 npm test。
- pond-scene.js：夏日池塘、阔叶树、自然岸边、三把椅子、天空与水面。
- style.css：响应式界面。
- vendor/：Three.js 0.186.1 及其 MIT 许可证。
- start.ps1、启动游戏.cmd：Windows 无依赖启动器。
- server.cjs：可选的 Node.js 本地服务器。有 Node.js 时可运行 npm start。
- 初步钓鱼游戏设计方案..md：原始参考。
- snapshots/：各可运行版本的 ZIP 备份。

所有模型由代码中的几何体创建，未使用付费或远程图片、贴图和模型。Three.js 官方资料：[安装](https://threejs.org/manual/en/installation.html)、[文档](https://threejs.org/docs/)。

V0.1、V0.2 及 V0.3 的可运行 ZIP 保存在 snapshots，可按版本回退。
