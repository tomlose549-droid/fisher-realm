# 湖畔慢时光 · V0.1

第一人称 3D 钓鱼游戏的首个场景版本。固定钓位、湖泊动态水面与反射、木质码头、程序生成的树林和远山、划艇与第一人称鱼竿。

## Windows 一键试玩

1. 如收到 ZIP，请先完整解压到普通文件夹。
2. 双击 **启动游戏.cmd**，浏览器会自动打开游戏。
3. 游玩期间保留启动窗口，关闭窗口即停止服务器。

无需安装 Node.js、Python 或任何开发工具；启动器使用 Windows 自带的 PowerShell。全部 3D 依赖已保存在 vendor，运行时不需要联网。请使用支持 WebGL 2 的 Chrome 或 Edge，保持浏览器图形加速开启。不要直接双击 index.html。

启动器默认使用 http://127.0.0.1:5173/，端口被占用时自动尝试 5174–5183，实际地址见启动窗口。服务只监听本机。

## 操作

右上角齿轮为设置入口，点击展开操作提示、回到钓位、画质和全屏。点击面板外、再次点击齿轮或按 Esc 收起；快捷键随时可用。

| 操作 | 功能 |
| --- | --- |
| 按住右键并拖动 | 左右上下环顾，可转身看岸边 |
| 方向键 | 转动视角 |
| R / 回到钓位 | 恢复初始视角 |
| F / 全屏按钮 | 切换全屏，Esc 退出 |
| 画质按钮 | 精细 / 流畅切换 |
| 右上角 ? | 查看说明 |
| 触屏单指拖动 | 环顾 |

玩家位置固定，不支持走动。本版按设计方案第一阶段实现，尚未加入抛竿、咬钩、鱼获和数量统计。

## 继续开发

- index.html：游戏入口与中文界面。
- main.js：Three.js 场景、模型、水面、镜头与交互。
- style.css：响应式界面。
- vendor/：Three.js 0.186.1 及其 MIT 许可证。
- start.ps1、启动游戏.cmd：Windows 无依赖启动器。
- server.cjs：可选的 Node.js 本地服务器。有 Node.js 时可运行 npm start。
- 初步钓鱼游戏设计方案..md：原始参考。
- snapshots/：各可运行版本的 ZIP 备份。

所有模型由代码中的几何体创建，未使用付费或远程图片、贴图和模型。Three.js 官方资料：[安装](https://threejs.org/manual/en/installation.html)、[文档](https://threejs.org/docs/)。
