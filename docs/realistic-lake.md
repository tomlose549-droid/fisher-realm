# 初始湖泊写实接入（V0.77.0，待审）

仅电脑版美国奥基乔比湖接入已确认样板。低档保留0.76.1当前场景，中/高档使用同一写实生态。其他三张地图保留现有造型，中/高沿用原高档；手机版未修改。默认高档、25帧上限，沿用旧设备偏好。

## 文件与职责

| 模块 | 职责 |
|---|---|
| `map-registry.js` | 每图原有上下文、经典构建器及可选`loadRealistic`懒加载构建器 |
| `map-runtime.js` | 同一MapSession内替换显示资源、取消/超时、预编译、尺寸调整、环境恢复与释放 |
| `rendering/config.js` | 初始湖泊视觉参数、三档预算、三把椅子；引用原地图水位/岸线 |
| `rendering/assets.js` | 同源GLB/glTF/PBR/KTX2/HDR加载、缓存、版本地址、解码器与释放 |
| `rendering/terrain.js`、`vegetation.js` | 不规则地形/湖底、椅子、岩石/沉木/植被、分区/LOD/实例化 |
| `rendering/water.js` | 单水面、限频平面反射、简化折射/深度颜色/浅水透视、动态波纹 |
| `rendering/scene.js` | HDRI/PMREM、太阳静态阴影与近景限频动态阴影、薄雾、显示资源组合 |
| `rendering/resources.js`、`preparation.js` | 资源所有权、幂等释放、取消与准备期限 |
| `rendering/performance.js` | 整帧及分阶段统计、持续负载检测、降分辨率/反射更新及渐进恢复 |
| `main.js`、`render-settings.js` | 原输入/游戏时钟与显示接口衔接，独立设备偏好和性能面板 |
| `map-assets/summer-pond/`、`vendor/addons/` | 压缩运行素材及固定版本加载器/解码器，授权见素材目录SOURCES.md |

为新生态接入写实显示时，在对应地图定义声明自己的`loadRealistic`构建器，按同一生命周期返回接口；视觉配置与素材清单各自独立。不要复制主循环、钓鱼、输入或存档。当前`rendering/config.js`及构建器仍专用于初始湖泊，不应直接给其他地图复用这一份岸线。

## 兼容与准备

画质切换先暂停GameTime、释放输入，再释放旧显示资源、加载新资源并预编译；不更换钓鱼实例，不重置竿/鱼/抄网/相机。不消耗额外亮片或鱼线耐久。恢复环境/阴影后对保留的钓具材质重新准备，避免切换后只显示鱼线。

新场景准备总限45秒、材质准备20秒；超时/失败或主动取消可回低档。离开释放当前显示、解码器、纹理、阴影和反射目标，只保留全局渲染器、相机及设备。所有地图仍为原水域判定；植被、石块与沉木不注册碰撞。视效布局使用独立确定性随机数，不改变遇鱼随机过程。

世界地图和低档不请求写实模型/贴图。GLB、glTF外部BIN、KTX2、HDR、Basis JS/WASM逐文件添加同一发布版本，不在目录地址拼接查询串。GitHub Pages子目录和旧HTML入口恢复复用原发布机制。画质、自动调节、统计与帧率只保存到设备偏好，三个进度存档保留。

## 本机性能测量与限制

1920×1080、Windows Chrome无头、Intel UHD Graphics 620（ANGLE D3D11）、本地HTTP；每档预热4.5秒后测量15秒，默认25帧上限、自动性能调节开启。中档平均24.7帧、分辨率100%；最终修复版本高档平均22.2帧，调至90%后末段采样约23.6帧（此前一次测量调至80%时末段约25帧）。无页面异常，末段未见长任务；完整原始记录位于本地`.qa/realistic-lake/performance.json`。

这是短时本机测量，不代表所有设备或公网冷启动速度，也不保证高档全程25帧。50/100只是上限，受硬件/刷新率限制。CPU耗时为JS提交整帧与各阶段的时间，不冒充GPU耗时；Draw Call/三角形包含当帧实际发生的反射、折射及阴影渲染，随视角与反射节奏变化。打开弹窗、隐藏标签页或重新准备画面后重置统计窗口，暂停时间不计入下一段帧耗时。

首次中高档需要下载压缩素材；GPU模型解码/着色器准备仍可能短暂占用主线程，发生在钓鱼计时暂停的准备界面。低档保留即时回退。长时实机与正式Pages冷缓存验收可在批准合并后补测，本PR不自动上线。
