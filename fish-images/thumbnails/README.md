# 背包缩略图

使用经用户同意的本地 Python/Pillow 工具，从统一配置中的19张原图生成。原图及透明底原图均保留原路径，不覆盖。

运行：`python scripts/build-inventory-thumbnails.py`（开发时需要 Pillow 与 Node；游戏运行不需要 Python）。最长512像素、最高384像素，保持原始宽高比与透明通道，WebP采用无损编码。

当前总大小2,652,014字节，原图合计29,405,419字节，减少约91%。目录保持原图相对路径结构，扩展名统一为webp。新增鱼暂未生成缩略图时，加载器可回退至配置中的原图。

加载策略：场景进入后延迟1.5秒，在浏览器空闲时后台仅预加载已解锁鱼种的缩略图（未解锁鱼种不请求图片）；后台最多同时1张。背包和鱼堆中当前可见的鱼图优先下载，滚动后再显示其他图片；总并发上限4张。相同图片共享下载与内存缓存。单次超时8秒，前台超时最多重试一次，重试重新排队；连续超时显示重试提示，不继续下载更大的原图。缩略图缺失或无法解码时仍可回退原图。关闭背包或重新渲染时清理可见性观察器。
